# Tree Field Survey (web app)

Tablet app for collecting tree data on site from a topographic survey drawing: open a field pack made in the
office, tap a tree, take photos (whole tree, leaf, bark) and record species, height, girth, crown spread and
condition. Works offline once opened; data stays on the tablet until it is exported as a zip.

Open: https://jianghp0818-prog.github.io/tree-field-survey/
